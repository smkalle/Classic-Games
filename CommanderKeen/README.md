# Commander Keen (Tribute Edition)

A single-page HTML recreation inspired by Commander Keen: Marooned on Mars. This tribute includes a title screen, pixel-art sprites, collectibles, enemies, and a compact level to explore.

## Quickstart

1. Open `index.html` in a modern browser.
2. Press **Enter** or **Space** on the title screen to start.

## Controls

- **Left / Right Arrow**: Move
- **Z or Up Arrow**: Jump
- **X**: Toggle Pogo Stick
- **C or Space**: Fire Raygun
- **P**: Pause

## Objective

Collect all four ship parts to complete the mission and escape Mars.
